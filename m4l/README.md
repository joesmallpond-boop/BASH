# BASH! Key Lock (Ableton Live 12, Max for Live)

Makes BASH! follow your Live set's key and scale.

## Use it

1. Drag **BASH Key Lock.amxd** onto the MIDI track that has BASH! on it, **before** BASH!.
2. Turn on **Scale** in Live's control bar (or a clip) and pick a key and scale. BASH!'s Key and Scale switch to match within a moment, and follow any change.

Your MIDI passes straight through the device, so playing BASH! (or its arpeggiator) still works.

## How it works

The device watches Live's `root_note` and `scale_intervals` and sends, on MIDI channel 16:

| CC | Value |
| --- | --- |
| 102 | root note, 0 = C … 11 = B |
| 103 | scale notes 0–6 above the root, as bits |
| 104 | scale notes 7–11 above the root, as bits |

BASH! picks the scale with exactly those notes, or its closest relative for scales it doesn't have (Lydian Augmented, for example, becomes Lydian). It resends every 2 seconds, so a BASH! you load later picks the key up too.

## If Live won't load the .amxd

The `.amxd` is generated by `make_device.py` and hasn't been opened in Max yet. If Live rejects it: drag an empty **Max MIDI Effect** onto the track, click its edit button, open **BASH Key Lock.maxpat** in Max, copy everything into the device, and save it as `BASH Key Lock.amxd`.
